title: Pebble SDK 4.33.1 - Changelog
date: 2026-08-14
---

This is a hotfix for [SDK 4.33](/sdk/changelogs/4.33/). Apps compiled with
SDK 4.33.1 still install and run on firmware 4.33 and 4.33.1, but the
recognizer crash fix below only ships on firmware 4.33.2; this hotfix
only updates the emulator.

### Changes to Firmware

* Fixed a crash when adding the new touch recognizers
  (``app_touch_navigation_enable()``) to an app.

### Changes to SDK

None.

### Changes to Emulator

* The emulator now runs firmware 4.33.2, which includes the recognizer
  crash fix.
